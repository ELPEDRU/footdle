❓ HOW TO PLAY

  • Guess the mystery footballer using the search box — pick a name from the suggestions.
  • Each guess reveals clues: green = correct, yellow = close, red = wrong.
  • For age, an arrow shows whether the real player is older ⬆️ or younger ⬇️.
  • Pick a difficulty — more attempts on Easy, fewer as it gets harder.
  • 🔥 Daily Challenge gives everyone the same mystery player once a day.
  • 💡 Use one free Hint per game if you're stuck.
  • 📋 Share your results as an emoji grid once the game ends.
  • 🏆 Unlock Achievements for special ways of winning.
